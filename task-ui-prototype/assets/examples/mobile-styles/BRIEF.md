# 见山商品目录 · 移动端视觉方向 R2

2026-09-25。这是新项目设计试跑的代表页，范围仍为首页、商品列表、商品详情；当前先比较商品列表的视觉语言，尚未选定，不把信息预览面板视为已完成的商品详情页。

## 输入与比较方式

- 用户：服装门店管理员。主要动作：搜索商品、按状态/分类/标签筛选、核对商品信息。
- 载体：手机网页原型；不画系统状态栏或宿主控件。390×844 主画布，360×800 与 320×740 补查。
- 品牌资产：无。演示店名、数据与 SVG 衣服示意均为本次构造。V2 只提供业务语义，没有引用其既有视觉设计。
- 三稿共用同一份数据、8 款商品、字段、状态、筛选条件和操作位置。搜索均在顶部，筛选均在面板，点击记录均打开同一信息预览。
- 列表价格取演示 SKU 的最低价，本组每款 SKU 同价；这不是既有 V2 列表接口的字段。无库存数量、无 API、无真实写入。

## 视觉主张

| 方向 | 具体手法 | 取舍与后续扩展 |
|---|---|---|
| 纸本目录 | 宋体标题/名称，纸色背景，朱红行动色，文字在左、直边图片在右，记录以横线连续分隔 | 阅读气质更强，后续高频操作页需克制标题与留白；首页和详情延续字排与分节 |
| 柔和工作台 | 无衬线字阶，白色功能组承载连续记录，圆润图像和控件，浅蓝工作底，导航单独成组 | 空间使用较宽松；后续表单在单一工作面分组，避免卡片嵌套 |
| 机能终端 | 低亮深色，编码/金额等宽，方角分区，每条记录内把价格与状态分格，强调色低饱和 | 核对感更强，深色偏好和强光表现需另验；后续指标与规格继续按字段基准对齐 |

共同输入字号 16px、辅助/状态 14px、按钮目标至少 44×44；具体字阶、色值、间距由每个方向的 CSS 定义。长名称自然换行，保留价格、单位与状态。页面自然滚动；固定导航留正文占位，安全区使用 env 值。短筛选使用底部面板，有取消/应用、焦点进入与返回；未应用选择不改变结果。

独立的比较工具提供灰度检查与 CSS 文字 200% 检查；它们不属于未来产品 UI，也不等同原生动态字体或真机验证。商品信息面板仅用于比较过程；首页、完整详情及其他入口不在当前样板中实现。

## 运行

在本目录执行 `python3 -m http.server 8769 --bind 127.0.0.1`。访问 `http://127.0.0.1:8769/` 切换与操作；`/compare.html` 在桌面并排显示三个 390×844 画布，可切灰度；窄窗口会缩窄或换行，尺寸说明以实际视口为准。

全部资源本地提供，不安装依赖，不连接生产服务。浏览器证据和未验证项见 [VERIFICATION.md](VERIFICATION.md)。用户尚未选择三套中的任意一套。
