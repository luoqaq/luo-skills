# 任务模式（开放清单）

阶段 2 按需读取：按用户动作组织信息，不按行业分类或绑定风格。清单开放，路径按任务裁剪；无法归类就按实际动作设计，新模式经真实项目验证后再补。

页面职责与表现力见 [PC 参考](pc-design-reference.md) §2；视觉方向按 [SKILL.md](SKILL.md) 阶段 2 决定。

## 管理操作

- **识别信号**：查找、编辑、审批、批量处理
- **核心任务路径**：筛选/查找 → 选中（可批量）→ 执行操作 → 确认反馈 → 回到列表原位
- **组织与状态**：筛选关联列表、主操作位置稳定；单选/批量选中清晰，操作有反馈且返回原位
- **常见失败**：筛选与结果脱节；批量操作无确认无反馈；操作后丢失上下文

## 监测分析

- **识别信号**：看趋势、发现异常、比较、下钻
- **核心任务路径**：扫关键指标 → 发现异常/变化 → 下钻原因 → 记录或转出处理
- **组织与状态**：指标分主次，时间/筛选范围显眼；显示数据时效与加载状态，异常高亮且可下钻
- **常见失败**：所有指标同等强度；图表与表格各说各话；异常埋在海量正常数据里

## 研究阅读

- **识别信号**：阅读、理解、核对证据、比较观点
- **核心任务路径**：读结论 → 核对支持/反面证据 → 比较观点 → 形成判断或保存
- **组织与状态**：结论在前，正反证据对应且有来源/时间；控制阅读宽度，提供章节导航
- **常见失败**：结论埋在段落里；证据无来源；阅读区被操作区挤压

## 内容浏览

- **识别信号**：浏览、筛选、预览、收藏、选择
- **核心任务路径**：浏览/筛选 → 预览 → 比较候选 → 选择/收藏 → 查看已选结果
- **组织与状态**：按选择依据分配图片/属性比例；预览到详情路径短，筛选条件、多选和已选结果可见
- **常见失败**：属性信息不足以支持选择；预览到详情跳转丢失筛选上下文

## 创作编辑

- **识别信号**：输入、编辑、预览、调整、保存
- **核心任务路径**：定位编辑对象 → 修改 → 局部预览反馈 → 保存 → 检查结果
- **组织与状态**：编辑对象与工具关系清楚；草稿/已保存/未保存可辨，支持撤销与结果预览
- **常见失败**：保存状态不明；工具与对象空间关系混乱；撤销缺失
