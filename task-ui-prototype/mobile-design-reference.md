# 移动端页面设计参考

使用时机见 [主流程](SKILL.md#按需读取)。适用于手机网页、小程序和 App 的网页原型；数值是设计起点，用户简报或已选设计系统优先，偏离后仍须可读、可点、无遮挡。

## 1. 先识别载体与使用方式

| 载体 | 先确定 | 原型边界 |
|---|---|---|
| 手机网页 / H5 | 浏览器或 WebView、导航与返回路径 | 默认不画假状态栏/设备外框；浏览器返回与站内路径一致 |
| 小程序 | 宿主平台、标准/自定义导航、tabBar 与顶部占位 | 宿主与业务区域分开，避免重复导航；扫码、相册等网页模拟不算宿主接通 |
| iOS / Android App | 目标平台、设计系统、系统栏与应用导航分工 | 网页只能表达原生意图，不能证明系统手势、键盘与权限流程 |

载体缺省与设计起点按 [阶段 1](SKILL.md#1-明确输入)。仅在延续产品时沿用原结构，不适合手机则说明并调整；不混画平台控件。设计依赖具体宿主 API、尺寸或版本时再核对官方文档。

从快速查看、连续处理、阅读或长输入判断首屏和操作位置；不因“移动”自动增加扫码、定位、通知等能力。

## 2. 按任务重排，不缩小 PC

写清**当前判断 → 必须看到的信息 → 下一步动作**。双端保留业务含义、状态、单位与结果反馈，改变呈现而不删功能。任务路径见 [task-patterns.md](task-patterns.md)。

| 任务 | 移动端取舍 | 保留能力 |
|---|---|---|
| 管理列表/筛选 | 主标识、状态与决策字段形成连续列表；常用条件外露，复杂筛选进面板/独立页 | 生效条件、结果数、清除入口可见；返回恢复条件与位置 |
| 横向比较 | 关键列用紧凑表；必要时局部横滚并提示其他列、固定标识 | 列名、单位、比较关系；不能一律改卡片、藏列或缩字号 |
| 批量处理 | 显式选择模式，显示已选数、范围、退出和批量操作 | 当前页/结果范围清楚，打开记录与勾选不冲突，结果有反馈 |
| 监测分析 | 结论/异常与时间范围在前，趋势和明细纵向展开 | 坐标、单位、范围、数据点可查；点击读数替代仅 hover |
| 研究阅读 | 结论、证据按阅读顺序；侧栏转为关联段落/章节入口 | 来源、时间、正反证据关联与阅读位置 |
| 图片/内容选择 | 按选择依据分配图文比例；属性比较优先列表，看图选择可用网格 | 筛选上下文、已选状态、预览到选择的短路径 |
| 表单/创作编辑 | 单列分组，真实阶段才分步；复杂编辑用整页，短选择用面板 | 标签、草稿、错误、保存反馈；编辑/预览不丢输入 |

断点按内容何时放不下选择，转换附近检查顺序、可达性与状态保留；PC 侧栏、悬浮操作和多列比例不是手机模板。

## 3. 导航、主操作与容器

- **导航**：少量高频同级目的地可用底部导航，单流程不硬加 tabBar；区分模块切换、页内切换与操作，不把新增/保存伪装成导航。
- **返回**：区分返回与关闭，恢复筛选、已选、滚动位置；直接进入详情时提供列表/上级入口。仅可能丢失未保存输入时提醒或恢复草稿。
- **主操作**：按时机放内容内、表单末尾或固定底部。固定栏用于滚动中持续需要的操作，并留正文占位；避免导航、批量栏、保存栏叠加。页面自控导航可切成操作栏，宿主 tabBar 则须遵守平台能力，不能用 HTML 覆盖冒充替换。
- **容器**：短选择/少量筛选可用底部面板；长内容、频繁键盘输入优先整页；简短关键确认才用对话框，避免面板嵌套。
- **模态**：关闭可见，取消/应用明确，未应用条件不生效；背景不滚动或接收点击，面板末项可达。焦点进入、留在模态内，关闭后回到触发位置；拖拽不是唯一退出方式。

## 4. 密度与视觉基线

以下为 **CSS px**，不等同设备物理像素、原生 pt/dp 或小程序 rpx。

| 项目 | 默认起点 | 调整依据 |
|---|---|---|
| 页面左右边距 | 16；密集 12，阅读 20 | 字段完整，触控区域充足 |
| 区域内 / 区域间距 | 8–12 / 20–24 | 连续数据靠对齐和分隔线，不默认每行套卡片 |
| 正文 / 辅助 / 标题 | 16 / 14 / 20–24 | 12 仅用于非关键附注；状态、金额等决策字段不靠小字塞下 |
| 输入文字 | 16 起 | 可读，并减少 iPhone Safari 小字号输入聚焦自动放大（[WebKit 实现](https://raw.githubusercontent.com/WebKit/WebKit/main/Source/WebKit/UIProcess/API/ios/WKWebViewIOS.mm)）；具体行为按设备验证 |
| 按钮、输入高度 | 48 起 | 多行内容自然增高，不硬裁 |
| 独立交互目标 | 至少 44×44 | 图标可小，热区补足且不重叠 |

44×44 是本 Skill 默认值，**不是 WCAG AA 统一最低值**；[WCAG 2.2 SC 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)为 24×24 CSS px，并有间距等例外。行内链接不强撑 44 高；原生交付按平台核对，例如 [Android 的 48×48 dp 建议](https://developer.android.com/guide/topics/ui/accessibility/apps)。

大标题、装饰和汇总不挤掉首个有效任务；用真实长度检查中文名称、金额、状态和多行按钮。仅非关键文本可截断，完整内容须可查。视觉语言见 [移动端预设](mobile-visual-presets.md)，这些数值不替代字排与构图设计。

## 5. 触控、输入与反馈

- 核心操作常驻或有明确更多入口；hover、右键、长按、滑动、拖拽可作捷径，但需单点替代。
- 按下、选中、提交中、成功/失败可辨；防重复提交，失败保留输入并可重试；不可逆操作按风险确认/撤销，不为普通点击增加确认。
- 字段有标签、错误贴近字段；`type` / `inputmode` / `autocomplete` 提示键盘而非替代校验。编号保留字符串语义，不能丢前导零。
- 键盘出现时字段、错误与下一步可达；固定栏避让或回到内容流，处理方式记入简报。
- 控件有可读名称与可见焦点，状态不只靠颜色；文字放大允许重排，不以裁关键内容或禁缩放维持截图。
- 按路径补空/加载/失败状态；模拟反馈明确标注，不冒充真实保存成功。

## 6. 视口、安全区与滚动

- 设置 `width=device-width, initial-scale=1` 并允许缩放；内容延伸到屏幕边缘时才加 `viewport-fit=cover` 并处理安全区。
- 优先文档滚动与自然高度；填屏可用 `min-height: 100dvh`，避免固定 `100vh` 加 `overflow: hidden` 裁内容。动态视口单位不等于键盘避让；确有需要再用 [VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)。
- H5 用 [env(safe-area-inset-*)](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/env)，宿主/原生取平台值，不硬编码底部 34px。文字、控件避让，顶部/底部/正文不重复累加 inset；正文留出固定栏高与安全区。
- 默认一个主要纵向滚动区；模态或二维数据可独立滚动，局部横滚需可发现且不吞纵向滚动/系统手势。打开面板或键盘后检查末项仍可达。
- 平台布局意图可参考 [Apple 布局指南](https://developer.apple.com/design/human-interface-guidelines/layout)。桌面 inset 可能为零；模拟值、假系统栏与宿主示意均须声明，不能算平台验证。

## 7. 验收与证据边界

默认 **390×844** 主视口、**360×800** 窄屏视口（CSS px），是测试画布而非指定设备；用户指定优先。按页面相关状态检查，不要求穷举所有组合。

| 检查 | 方法与通过证据 |
|---|---|
| 布局与长内容 | 两视口实际渲染，长列表/表单滚到末项，覆盖长名称与大金额；记录截图，无整页横溢、遮挡，局部横滚可识别 |
| 触控目标 | 点主操作、图标、复选项、更多并量热区，检查相邻误触；记录是鼠标、触控模拟还是真机 |
| 任务闭环 | 走筛选/选择 → 详情或编辑 → 返回；记录反馈、条件/已选/位置恢复，分别检查浏览器返回与可见返回 |
| 输入与失败 | 相关表单输入到末项，制造错误/失败再重试；输入不丢，提示和下一步可达 |
| 安全区与浮层 | 打开、滚动、关闭；正文、末项与关闭可达，背景不误操作，记录真实/模拟 inset |
| 字体与焦点 | 代表页 200% 文字放大/缩放，记录方法；关键内容完整，焦点可见且不逃到模态背景 |

浏览器尺寸、触控模拟、真机与宿主分别记录。窄屏/模拟不能证明软键盘、系统手势、权限或宿主 API；缺项列待验证，不阻塞如实交付网页原型。审查与交付规则见 [主流程](SKILL.md#4-验收必须)。

**否决项**：缩放 PC 整页冒充适配；核心操作仅靠 hover/手势；热区重叠；关键字段、末项或唯一操作被遮且无法滚动到达；裁关键内容或禁缩放；模态无法退出；返回丢任务上下文。须修复后复验。
