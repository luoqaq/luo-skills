# 移动端视觉预设

阶段 2 按需读取；移动端可读、触控、返回与安全区仍遵守 [移动参考](mobile-design-reference.md)。三套规则可复用、改造，也可提出新方向，不按行业绑定风格。

## 如何使用

按 [主流程阶段 2](SKILL.md#2-确定方向) 处理选择、委托、同题比较和混搭。选用候选后读取其规则与样板，在简报中写明保留/调整的手法；色号和尺寸是起点，视觉关系才是复用对象。页头、主体、面板须使用一致语言，不能只改标题。预设不决定页面清单或导航是否存在。

## 预设差异

| 视觉维度 | 纸本目录 | 柔和工作台 | 机能终端 |
|---|---|---|---|
| 字排 | 宋体标题/名称，墨色正文，清晰的无衬线辅助字 | 无衬线粗细对比，圆润而明确的标题和数字 | 中文无衬线，编码/金额/计数等宽对齐 |
| 构图 | 页眉、横线、连续通栏记录，图在文字旁 | 浅底与白色功能组，图文留白，重点金额嵌入记录 | 固定对齐基准，分段控制区，记录内价格/状态分格 |
| 边界与材质 | 纸色平面、直边图片、不套记录卡片 | 大圆角功能容器、柔和色面、轻微单层阴影 | 低亮深色、实线网格、0–4px 方角、无辉光 |
| 控件 | 印刷式下划线选中、描边与实色按钮 | 柔和选中底色、圆润控件、浮起的导航容器 | 实色选中块、清楚的边框与边缘标记 |
| 色彩作用 | 朱红用于行动与当前项，商品状态独立 | 蓝色用于行动，浅蓝承接分组，状态用文字 | 克制的薄荷色用于当前项/行动，不把所有文字染成信号色 |

### 纸本目录

- **主张**：像一份可以操作的商品目录，靠字排与连续横线建立秩序。适合逐项浏览、识别与阅读属性；高频批量页应压低标题尺度和空白。
- **规则**：标题和名称用系统宋体栈；操作与属性用系统无衬线。纸色 `#f4efe5`、墨色 `#292820`、强调 `#a53c2f`。页面边距 20，标题 32，名称 18，辅助字段 14，价格 22；记录之间用横线，商品图直边。
- **允许变化**：纸色冷暖、强调色、图文比例、横线疏密；标题挤占任务时缩小，不拿装饰当能力。
- **失效方式**：所有文字都用宋体、小字模拟印刷、纸纹影响可读、红色用于所有状态，或者只把普通卡片底色改成米色。
- **跨页示例**：需要首页时用数字摘要与横线分节；需要详情时用题名、图版和属性段落。表单标签仍用无衬线，不模拟纸质表单的窄填写格。

### 柔和工作台

- **主张**：以清晰的功能分组降低连续操作的压迫感。适合查找、选择、轻量编辑；超长列表应保留清楚的行边界。
- **规则**：系统无衬线，标题/金额较粗；浅底 `#edf2f9`、白色工作面、正文 `#26334b`、强调 `#355bd8`。标题 30，名称 16，辅助字段 14，价格 22。功能组圆角 20–24，图片 12–16，控件 12；一层轻阴影即可。
- **允许变化**：温冷、强调色、圆角幅度、图片形状；不是每一个东西都做胶囊，也不要求每条记录单独套卡片。
- **失效方式**：卡片套卡片、低对比浅灰小字、仅加圆角/阴影但构图与其他稿一致。
- **跨页示例**：需要首页时按任务组织少量功能组；详情在单一工作面分组，操作与内容分层。若有底部导航，可单独成组并留占位。

### 机能终端

- **主张**：用网格与数字对齐表达核对的精确感。适合编码、金额和状态扫描；强光、长阅读或用户偏好浅色时，应验证浅色变体或另选语言。
- **规则**：中文名称用系统无衬线，编码/金额/计数用系统等宽。底 `#171e21`、工作面 `#20292d`、正文 `#e1e8e6`、辅助 `#b2c0bf`、强调 `#99cbb5`。标题 26，名称 16，辅助字段 14，价格 20。方角、清楚的内外边界，正文对比优先于氛围。
- **允许变化**：明暗、低饱和信号色、图文比例、列线强度；不要求“终端”就全黑全绿。
- **失效方式**：中文全等宽、假命令行缩写、扫描线、荧光辉光、小字号密密麻麻，或者只把普通后台改深色。
- **跨页示例**：需要首页时对齐指标与时间范围；详情用属性字段网格。浅色变体也保留对齐与分格，不添加装饰读数。
